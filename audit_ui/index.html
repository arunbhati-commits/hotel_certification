What should each test case folder contain?
  • Search, Detail and Review request + response.
  • Hold and/or Book request + response (and Confirm Hold if you held first).
  • Every booking must have a Booking Detail call: after booking, add the Booking Detail request + response with the updated status.
  • For cancel cases: Cancel request + response, then call Booking Detail again so it shows the updated status (CANCELLED).
  • Test Case 14: the Booking Detail response of every test booking showing CANCELLED.
